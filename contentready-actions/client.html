ContentReady BRAT

Médias stockés dans une Release GitHub. Le job Actions télécharge les assets, extrait 15 s, isole la voix, détecte les marqueurs de cut, monte les clips et exporte le MP4.

1. Accès GitHub

Token fine-grained limité à ce repo : Contents Read/Write + Actions Read/Write. Ne le colle pas dans le chat.

2. Ajouter des médias

Les fichiers ne sont plus commités dans Git. Ils vivent dans la Release contentready-media.

3. Morceau

Aucun audio chargé

4. Clips

Ctrl/Cmd + clic pour sélectionner plusieurs vidéos. Le montage évite de reprendre le même intervalle source pour les plans d’au moins 1 seconde.

5. Choisir les 15 secondes

0.00 → 15.00
